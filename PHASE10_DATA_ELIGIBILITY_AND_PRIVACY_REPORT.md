# Phase 10 — data eligibility and privacy

**Decision, 8 November 2026:** The [Verenkotte–Spann OSF project](https://osf.io/zv8xy/) is publicly readable, but the checked records do not establish the specific rights needed to retain individual responses, fit a reusable model, share derivatives, or publish results from a new analysis. **No OSF respondent-level records were downloaded, retained, minimized, or modelled in Phase 10.** This is an unresolved authorization decision, not a conclusion that all academic reading or analysis is legally prohibited. No researcher was contacted.

The [replication README](https://osf.io/download/tw6dm/) has no license or reuse terms; the fetched 1,202-byte README had SHA-256 `9438cae6029cbcf70e8d0527825c27ade8be9f3116e7c271d35e8de1a986b7c6`. The prior [Phase 9 candidate matrix](phase9_research/candidate_matrix.csv) screened seven sources. A focused Phase 10 search for a compatible, explicitly licensed experimental dataset did not find one that jointly supplied an assigned personalization condition, a direct ad-specific intrusion response, usable individual data and suitable reuse terms. Licensed general-ad intrusion surveys remain separate research; privacy concern is not an intrusion label, and Criteo's binary engagement treatment has no perception outcome. No unrelated respondents were merged.

## Implemented research-only intake, currently blocked

`phase10_research/intake.py` is an **in-memory preparation and validation module**, with no loader, download, model fit or export. `phase10_research/rights_status.json` records the actual OSF status as unverified, so an attempted intake raises `EligibilityError` before reading a row. A future reviewer must record a source-matching dataset license or written grant, its citation, reviewer, and positive evidence for academic analysis, local retention, model training, derivatives and publication, plus privacy review. A manually filled flag is a software gate, **not itself proof of a legal right**; the cited source and scope still require human review. The current flags are false because permission was not verified, not because prohibition was established.

If the gate is legitimately opened later, the allowlist copies only `Targ`, `Trans`, `PPI`, `PPR`, `PP` and `ITC`. A transient respondent key is checked for missing or duplicate between-subject responses and omitted from the returned records. IP, exact coordinates, `ResponseId`, `PROLIFIC_PID`, contact details, timestamps, free text, demographics and device fields are not copied. Validation rejects extra or missing fields, nonbinary treatments and missing, nonfinite or out-of-range 1–7 ratings. This strict complete-case rule would need a documented missingness assessment before real use; it must not silently erase participants. Study-specific treatment labels distinguish no/city targeting in Study 1 from country/city in Study 2. Post-exposure `PPR`, `PP` and `ITC` are kept only as separate outcomes, never as pre-launch predictors of `PPI`.

Dropping direct identifiers does **not** prove anonymity. Before any future use, review cell sizes, linkability, possible free-text content, permitted aggregate disclosure, data location and access controls. Any authorized raw-identifying input should be handled transiently in an isolated restricted process without diagnostic dumps. Restricted local retention requires a documented owner, access list, purpose and deletion date; none is currently authorized, so the present retention period for OSF respondent files is **zero**. Public reports should contain only permitted aggregate results with small-cell review. No OSF respondent file, minimized table, ID map or derived model is in this repository.

The repository ignores Phase 10 private/minimized/model directories and the named original OSF workbooks. `phase10_research/staging_guard.py` checks staged paths, including files force-added past `.gitignore`; run it immediately before each commit. The synthetic regression tests verify the rights gate, minimization, quasi-identifier rejection and staging rules. These controls reduce accidental inclusion; they do not replace a source-license review or guarantee that every possible sensitive filename is recognized.

**Eligibility to train now: no.** The next trigger would be independently verifiable source-specific reuse terms and an authorized, privacy-reviewed, minimized release or another genuinely compatible licensed dataset. This phase does not request an author email or participant contact.
